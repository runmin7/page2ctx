# HTML 다운로드

보고 있는 웹 페이지를 **Markdown / 순수 HTML / CSS 포함 HTML** 파일로 저장하거나 클립보드로 복사하는 Chrome 확장 프로그램이다.

사내 보안 정책 때문에 Claude가 브라우저 화면을 직접 볼 수 없을 때 쓴다. 조회한 화면(그룹웨어, API 정의서 등)을 파일로 받아 Claude에 컨텍스트로 넘긴다.

- **화면 그대로 저장**: JS 실행이 끝난 렌더링 상태를 저장한다. 조회 결과·입력값도 화면에 보이는 그대로 들어간다.
- **frame/iframe 병합**: frame/iframe 내용을 원래 위치에 합쳐 넣는다. 다른 출처(도메인)의 프레임도 포함한다.
- **설치가 단순함**: 외부 라이브러리와 빌드 과정이 없다. 폴더를 그대로 Chrome에 로드하면 된다.

## 설치

1. 이 저장소를 내려받는다.
2. Chrome에서 `chrome://extensions`를 연다.
3. 오른쪽 위의 **개발자 모드**를 켠다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고, `manifest.json`이 있는 폴더를 선택한다.
5. 툴바의 퍼즐 아이콘에서 **HTML 다운로드**를 고정(핀)한다.

- **요구 사항**: Chrome 116 이상
- **코드 갱신 후**: 확장 카드의 새로고침(↻)을 누르고, 대상 페이지도 새로고침한다.
- **로컬 파일(file://) 저장**: 확장 카드의 **세부정보 → 파일 URL에 대한 액세스 허용**을 켠다.
- **사내 정책**: 개발자 모드나 모든 사이트 접근 권한(`<all_urls>`) 확장이 정책으로 막혀 있으면 설치할 수 없다.

## 사용법

### 툴바 팝업
팝업은 항상 **현재 탭** 화면으로 열린다.

| 탭 | 기능 |
|---|---|
| 현재 탭 | 저장 대상 탭 제목 표시, **저장**(MD / 순수 HTML / CSS 포함), **복사**(MD / 순수 HTML) |
| 여러 탭 (N) | 체크한 탭을 탭별 개별 파일로 저장 |

여러 탭 목록은 아래 기준으로 미리 체크된다.
- Ctrl·Shift+클릭으로 탭을 여러 개 선택해 두었으면 그 탭들이 체크된다.
- 선택한 탭이 없으면 현재 창의 모든 탭이 체크된다.
- `window.open`으로 뜬 별도 팝업 창의 탭은 `[팝업]`으로 표시되며, 기본은 체크 해제다.

### 우클릭 메뉴
- **페이지 저장 - {형식}**: 현재 탭 전체를 저장한다.
- **선택 영역 저장 - {형식}**: 드래그로 선택한 부분만 저장한다. 선택한 프레임이 기준이다.

### 단축키
| 단축키 | 동작 |
|---|---|
| `Alt+Shift+M` | Markdown으로 저장 |
| `Alt+Shift+P` | 순수 HTML로 저장 |
| `Alt+Shift+C` | CSS 포함 HTML로 저장 |

- 단축키를 누른 시점의 활성 탭을 저장한다.
- 확장 아이콘이 없는 팝업 창(결재창 등)에서는 단축키나 우클릭 메뉴로 저장한다.
- 단축키는 `chrome://extensions/shortcuts`에서 확인하거나 바꾼다. 다른 프로그램과 겹치면 비어 있을 수 있다.

### 결과 확인
- **저장 위치**: Chrome 기본 다운로드 폴더에 `제목_yyyyMMdd_HHmmss_{md|pure|css}[_sel].{md|html}` 이름으로 저장된다.
- **팝업에서 실행**: 팝업에 결과가 표시된다.
- **우클릭·단축키로 실행**: 툴바 아이콘에 배지가 잠시 뜬다. 자세한 내용은 아이콘에 마우스를 올리면 보인다.
  - `OK`: 저장 완료
  - `!`: 저장 완료, 일부 누락
  - `ERR`: 실패

## 저장 형식

| 형식 | 용도 | 크기 |
|---|---|---|
| **Markdown** (`.md`) | Claude 컨텍스트용 (권장) | 가장 작음 |
| **HTML (순수)** (`.html`) | 구조(표·폼)를 HTML 그대로 보고 싶을 때 | 작음 |
| **HTML (CSS 포함)** (`.html`) | 화면 모양까지 보존할 때 | 수백 KB ~ 수 MB |

### Markdown
순수 HTML 정리를 거친 뒤 변환한다.

- **표**
  - 일반 표는 MD 표로 바꾼다.
  - `colspan`은 빈 칸으로 채우고, `rowspan`은 아래 행에 같은 값을 반복한다.
  - 셀 안의 줄바꿈은 `<br>`로 남긴다.
- **레이아웃 표**
  - 표 안에 표가 있거나 열이 하나인 표는 레이아웃용으로 보고 블록으로 펼친다.
  - `제목칸(th) + 값` 행은 `**제목**: 값`으로 만든다.
- **그 밖의 요소**
  - 제목·목록·링크·굵게·코드·`pre`를 변환한다.
  - 입력값은 `` `값` ``, 체크박스는 `[x]` / `[ ]`로 남긴다.

### HTML (순수)
구조와 텍스트만 남긴다.

- **속성**: `id`·`href`·`colspan` 같은 의미 있는 속성만 남기고, `class`·`style`·`data-*` 등은 지운다.
- **제거하는 요소**: 화면에 안 보이는 요소(`display:none`), 숨은 입력값(`input type=hidden`), `svg`
- **감싸기 요소**: `span`·`font`·`tbody`·이름 없는 앵커처럼 감싸기만 하는 요소는 벗긴다. 다른 확장이 끼워 넣은 커스텀 태그(`<deepl-...>` 등)도 벗긴다.
- **줄바꿈·공백**
  - `colgroup`, 빈 블록, 앞뒤·연속 `<br>`을 정리한다.
  - 표 셀 안의 `<p>`는 `<br>`로 바꾼다. 단, 표를 품은 레이아웃 셀은 그대로 둔다.
  - `&nbsp;`, 연속 공백·줄바꿈, 주석을 정리한다.
- **프레임**: 프레임 내용은 `<section data-frame-src="...">` 안에 펼쳐 넣는다.

### HTML (CSS 포함)
- 적용 중인 스타일시트를 하나의 `<style>`로 합친 단일 파일이다. 다른 출처의 CSS와 `@import`도 펼쳐 넣는다.
- frame/iframe은 `srcdoc`로 내장하고, frameset은 원래 화면 위치에 배치한다.

### 공통
- `<script>`와 이벤트 속성(`onclick` 등)을 제거한다.
- 이미지(`img`·`picture`·`canvas`·동영상)는 제거하고, `alt`가 있으면 텍스트로 남긴다.
- input·select·textarea는 현재 입력값으로 고정해 저장한다. 비밀번호와 파일 입력값은 비운다.
- 링크는 절대경로로 바꾼다.
- 파일은 UTF-8로 저장된다. 원본이 EUC-KR이어도 변환된다.
- 파일 맨 위 주석에 형식·제목·원본 URL·저장 시각이 남는다.

## 누락 알림

다른 출처 프레임이나 CSS를 가져오지 못해도 저장은 계속 진행한다. 다만 조용히 빠뜨리지 않고 아래처럼 알린다.

- 빠진 프레임 자리에는 `(프레임 내용을 가져오지 못했습니다)`를 남긴다.
- 팝업 결과나 아이콘 배지(`!`)에 `일부 누락: 프레임 N개, CSS N건`을 표시한다.
- 크기가 0인 프레임(추적용 등)은 본문이 아니므로 경고 없이 제외한다.

## 제한

- `chrome://` 페이지, 웹스토어, PDF 뷰어는 Chrome 정책상 저장할 수 없다.
- 절전(메모리 세이버)으로 잠든 탭은 실패할 수 있다. 탭을 한 번 열어 본 뒤 다시 시도한다.
- Shadow DOM 내부와 canvas로 그린 차트는 저장되지 않는다.
- CSS 포함 모드에서 CSS 안의 배경 이미지·웹폰트 경로는 원본 그대로 둔다. 원본 서버에 접속할 수 없는 곳에서 열면 표시되지 않는다.
- Markdown에서 `pre`가 아닌 곳의 들여쓰기 공백은 한 칸으로 줄어든다.

## 보안·개인정보

- 저장한 내용은 내 PC의 다운로드 폴더나 클립보드로만 간다. 제3자 서버로 보내지 않는다.
- 네트워크 요청은 CSS 포함 모드에서 원본 페이지가 쓰던 CSS 파일을 다시 받아오는 것뿐이다.
- 비밀번호·파일 입력값은 비우고, 순수 HTML·Markdown에서는 숨은 입력값도 뺀다. 그 밖에 화면에 보이는 입력값과 링크 주소는 그대로 저장되니, 외부로 공유할 때는 내용을 확인한다.
- 저장하는 동안 원본 페이지 DOM에 임시 속성(`data-htmldl-*`)을 붙였다가 바로 제거한다. 프레임 식별용 `data-htmldl-id`만 남는다.

## 권한

| 권한 | 사용처 |
|---|---|
| `scripting` | 페이지와 프레임에 저장 스크립트를 주입한다 |
| `downloads` | 파일을 저장한다 |
| `contextMenus` | 우클릭 메뉴를 띄운다 |
| `offscreen` | 저장할 문자열을 Blob URL로 바꾼다 (data URL의 2MB 제한 회피) |
| `<all_urls>` | 다른 출처 프레임 주입, 여러 탭 저장, 다른 출처 CSS 가져오기에 필요하다 |

## 파일 구성

| 파일 | 역할 |
|---|---|
| `manifest.json` | 확장 설정(MV3), 단축키 정의 |
| `background.js` | 캡처 흐름 조율, 다른 출처 프레임 병합, CSS 대리 요청, 다운로드, 여러 탭 저장, 우클릭 메뉴·단축키 |
| `content.js` | 각 프레임에서 DOM 복제·정리·직렬화, Markdown 변환 |
| `offscreen.html`, `offscreen.js` | 문자열을 Blob URL로 변환 |
| `popup.html`, `popup.js` | 툴바 팝업(현재 탭 / 여러 탭) |

### 동작 흐름
1. `background.js`가 모든 프레임에 `content.js`를 주입한다.
2. 다른 출처 프레임에 `postMessage`로 식별 id를 부여한다.
3. 각 프레임이 자기 DOM을 직렬화한다. 같은 출처 하위 프레임은 부모가 직접 펼쳐 넣는다.
4. 다른 출처 프레임 결과는 `background.js`가 자리표시(`HTMLDL-SLOT-id`)에 병합한다.
5. offscreen 문서가 만든 Blob URL로 다운로드하거나, 팝업이 클립보드에 쓴다.
